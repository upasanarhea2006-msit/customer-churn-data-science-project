# Week 3 – Machine Learning Model Development & Evaluation

## Objective
Develop a detailed plan for the end-to-end development and evaluation of a machine learning model using Python.

## Project
The hypothetical Customer Churn Prediction problem was considered as a binary classification task.

## Work Completed
- Planned data preprocessing and cleaning.
- Designed missing-value treatment, categorical encoding, and feature scaling strategies.
- Planned feature engineering and feature selection.
- Defined appropriate train-test splitting and data leakage prevention methods.
- Evaluated potential machine learning algorithms for the classification problem.
- Planned model training and hyperparameter tuning.
- Designed cross-validation and validation strategies.
- Defined performance metrics including accuracy, precision, recall, F1-score, ROC-AUC, and confusion matrix.
- Outlined possible model deployment and monitoring approaches.

## Candidate Models
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- Support Vector Machine
- K-Nearest Neighbors

## Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Expected Outcome
A structured machine learning development and evaluation framework covering preprocessing, model selection, training, validation, performance evaluation, and potential deployment.
