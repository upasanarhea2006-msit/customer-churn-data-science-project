# Week 2 – Exploratory Data Analysis & Data Visualization

## Objective
Develop a comprehensive framework for Exploratory Data Analysis (EDA) and data visualization using Python.

## Work Completed
- Planned the data loading and initial inspection process.
- Identified numerical, categorical, ordinal, and temporal data types.
- Designed strategies for handling missing values and detecting outliers.
- Planned univariate, bivariate, and multivariate analysis.
- Defined descriptive and comparative statistical analysis techniques.
- Designed visualization strategies for identifying trends, relationships, distributions, and anomalies.
- Identified suitable Python libraries for data analysis and visualization.
- Planned methods for documenting and communicating analytical findings.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Expected Outcome
A structured and reusable EDA and visualization framework that can be applied to a suitable dataset for identifying meaningful patterns and insights.
